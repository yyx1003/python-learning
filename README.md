# python-learning

Python 学习练习代码。

## 内容

| 文件 | 说明 |
|---|---|
| `solution.py` | 存款买房问题：给定房价、年薪、月存款比例、半年涨薪比例，计算多少个月能存够首付；每满 12 个月输出一次月末存款 |

## 涉及知识点

- `input()` 与类型转换
- `while` 循环与计数器
- 浮点数复利计算（年利率按月计息）
- f-string 格式化：`{x:,.0f}`（千分位 + 四舍五入到整数）
- 取模判断周期：`number_of_months % 6 == 0`

## 运行

```bash
python solution.py
```

按提示依次输入：房价、年薪、月存款比例（如 30）、半年涨薪比例（如 7）。
